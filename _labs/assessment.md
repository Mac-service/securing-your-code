# Pre/post assessment

Use the same questions before and after the workshop. Allow 10 minutes and
score one point per correct answer. A learner may answer in plain language;
product labels are included in parentheses for scoring.

1. Which GHAS signal is designed to find a vulnerable data flow in source code?
2. Which control reviews a dependency change in a pull request, and what does
   it not prove about the final artifact?
3. Name two safe actions after a real secret is exposed.
4. Put these in order: remediate, detect, measure, triage, enforce.
5. What does pinning a GitHub Action to a full commit SHA protect against?
6. Name one SBOM format and one question an SBOM cannot answer by itself.
7. What evidence shows that a branch rule is enforcing a required security
   check rather than merely reporting it?
8. Define MTTD and MTTR.
9. Give one accessibility or low-bandwidth accommodation for this workshop.
10. What must be true before a temporary workshop repository is reused?

## Acceptance criteria

- **Knowledge:** at least 8/10 post-assessment answers are correct.
- **Operational:** the learner can produce one alert triage note, one passing
  remediation PR, and one enforced required check.
- **Safety:** zero real credentials, production repositories, or personal data
  are used; the reset checklist is complete.
- **Measurement:** the learner records a baseline and post-workshop value for
  at least two metrics, with a stated data source and time window.

The instructor records only aggregate scores unless learners explicitly consent
to retaining identifiable results.
