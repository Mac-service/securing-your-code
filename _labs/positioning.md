# Competitive positioning and source map

This is a learning-design comparison, not a product ranking. Links are
classified so instructors can distinguish official product guidance from
third-party practice material. URLs are intentionally kept public and do not
require credentials.

| Source | Label | Strength | Gap this workshop fills |
| --- | --- | --- | --- |
| [Microsoft Learn: GHAS](https://learn.microsoft.com/en-us/training/paths/github-advanced-security/) | Official | Structured GHAS learning path | Adds a timed, role-based lab flow and reset evidence |
| [ghas-lab-templates exercises](https://github.com/ghas-lab-templates/exercises) | Third-party/community | Supply-chain, secret-protection, and code-security exercises | Adds explicit GitHub attribution boundaries, acceptance criteria, and capstone measurement |
| [GitHub Workshops](https://workshops.github.com/) | Official GitHub | Facilitated workshop format | Adds low-bandwidth, accessibility, and troubleshooting guidance |
| [GitHub Security Lab](https://securitylab.github.com/) | Official GitHub | Research and secure-development expertise | Converts research context into beginner-to-operator practice |
| [Security Lab events](https://securitylab.github.com/events/) | Official GitHub | Time-bound security and CodeQL workshops | Adds durable, self-paced steps and reset guidance |
| [DevSecOps on AKS](https://learn.microsoft.com/en-us/azure/architecture/guide/devsecops/devsecops-on-aks) | Official Microsoft | Container/Kubernetes DevSecOps architecture | Keeps optional container/IaC coverage credential-free and repository-scoped |
| [AKS DevSecOps workshop](https://azure.github.io/AKS-DevSecOps-Workshop/) | Official Microsoft/Azure | Workshop positioning and platform context | Adds reproducible repository-scoped exercises without Azure credentials |
| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | Official OWASP project | Broad intentionally vulnerable application | Uses it only as a disposable learning target; this repo adds GHAS workflow evidence |

Official sources may change UI labels or availability. Instructors should
re-check plan requirements before each cohort and record the date of the
verification.
